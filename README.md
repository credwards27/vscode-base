# VSCode Base

Base shared configuration extension for VSCode.

## Installation

Clone the repository (or pull the latest changes):

```bash
git clone https://github.com/credwards27/vscode-base.git
```

Run the extension package `upgrade` command:

```bash
cd <path/to/package/>
npm run upgrade
```

## Upgrading

To upgrade the extension after it is already installed:

```bash
cd <path/to/package/>
npm run update
npm run upgrade
```

## Dependencies

### Environment

- `code` CLI tool
  - [Installing VSCode CLI](https://code.visualstudio.com/docs/configure/command-line)
